# ALU Design and Verification using SystemVerilog

## Overview
This project explores the design and verification of an Arithmetic Logic Unit (ALU) using SystemVerilog.

## Verification Components
- Design module
- Interface
- Driver
- Monitor
- Scoreboard
- Assertions
- Coverage
- Sequence item and sequence
- Agent and environment

## Verification Goals
- Check ALU operation behavior.
- Compare observed outputs against expected results.
- Practice testbench architecture and debugging.
- Explore assertions and functional coverage.

## Tools
- EDA Playground
- SystemVerilog
