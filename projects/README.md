# Verification Projects

This directory contains hands-on projects demonstrating RTL verification concepts and SystemVerilog/UVM skills.

## Projects

### 1. Dual-Port RAM Verification
- Design: Dual-port RAM
- Verification: SystemVerilog testbench and checkers
- Focus: Read/write behavior, reset behavior, and simultaneous port operations
- Status: In progress

### 2. UVM Practice
- Focus: Sequence items, factory registration, phases, and configuration database
- Status: In progress

## Verification Approach

For each project, I aim to document:
- Design specification and assumptions
- Test scenarios and expected results
- Simulation commands and tool used
- Actual simulation results and bugs found
